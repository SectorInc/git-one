# 🐍 Python Projects Portfolio

A collection of Python command-line projects demonstrating core programming skills including data structures, functions, loops, user input validation, and real-world problem solving.

---

## 📂 Projects

### 1. 🏧 ATM Banking System
**`atm_system.py`**

A simulated ATM with multi-user support, PIN authentication, and core banking operations.

**Features:**
- PIN login with 3-attempt lockout
- Withdraw funds with balance validation
- Check account balance
- Transfer funds between accounts with PIN confirmation
- Supports multiple user accounts

```bash
python atm_system.py
```

---

### 2. 💸 Personal Expense Tracker
**`expense_tracker.py`**

Tracks a user's daily expenses and provides a spending summary.

**Features:**
- Records multiple named expenses
- Displays formatted expense table
- Calculates total, highest, and lowest expense on request

```bash
python expense_tracker.py
```

---

### 3. 🎓 Grade Calculator
**`grade_calculator.py`**

Calculates and displays letter grades for students based on their numeric scores.

**Features:**
- Validates scores in the 0–100 range
- Maps scores to A–F letter grades
- Personalized output messages per student
- Supports grading multiple students in one session

```bash
python grade_calculator.py
```
